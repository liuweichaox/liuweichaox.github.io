FROM DATA TO DECISION

Understand one real run before claiming diagnosis or optimization.

The product starts from a decision the engineer must make, not from an algorithm. Six steps turn field data into evidence that can be compared, tested, and reused.

01

Define the process

Declare products, equipment, variables, units, quality objectives, and safety boundaries so the computer understands the question.

02

Connect equipment

Map controls, instruments, vision, inspection, and business data to stable, versioned process semantics.

03

Collect production data

Record actual recipes, stage trajectories, material, tooling, and other manufacturing context for each real run.

04

Close the data loop

Check missingness, time, units, and provenance, then link quality outcomes uniquely to the same run.

05

Diagnose the process

Compare like-for-like runs and form candidates with evidence, counterevidence, confounding limits, and validation advice.

06

Process optimization

Validate candidates through controlled experiments and choose more valuable next steps inside engineer-approved boundaries.

THE METHOD TOOLBOX

Choose an effective method for the engineering question—not one algorithm for everything.

Data quality, robust comparison, experimental design, causal validation, machine learning, Bayesian optimization, physical models, and LLMs each have boundaries. Use a simple method when it is enough; collect data or refuse when evidence is insufficient.

STATISTICSEXPERIMENTSMODELS
DATA

Data trust

Check completeness, units, time, provenance, versions, and drift before deciding whether data can be used.

COMPARE

Comparison and diagnosis

Use matching, robust statistics, stage trajectories, and context stratification to narrow candidates.

TEST

Experimental validation

Use controls, repetitions, blocks, randomization, and interventions to test whether a candidate survives.

OPTIMIZE

Sequential optimization

For expensive small-data problems, use GP, DOE, or constrained BO to select a more informative next experiment.
